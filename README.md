# Pickle Open Play Booking 🏓
A mobile-first GitHub Pages-ready PWA for pickleball Open Play reservations.

## Features
- Upcoming Open Play cards with remaining slots
- Player booking + waitlist
- Booking code and My Booking view
- Organizer dashboard
- Create/edit/delete Open Plays
- Registered-player list
- Public-link sharing
- PWA install support
- Local browser storage (no server required for demo)

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this ZIP to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will provide the public website URL.

## Important
This version uses `localStorage`, so bookings are stored only on the device/browser where they are entered. For true multi-user live booking, connect the project to Firebase Realtime Database or Firestore. The UI is intentionally structured so Firebase can be added next.
